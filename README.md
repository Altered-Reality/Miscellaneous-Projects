# 'TempControllerAnalysis.ipnyb'
This file is for the analysis of data collected for the temperature PID controller (Proportional-Integral-Derivative).
It uses a simple circuit consisting a capacitor, thermister, and resistor. The resistor is the heating element while the capacitance and thermistor change their physical properties in response to the heat and subsequent change in resistance.
This allows you to model the system response and calibrate the power input so you can maintain a target temperature with great precision; the PID itself calculates the error between the target value and current value, then dynamically adjusts various parameters to minimize this error.

Unfortunately the much more pertinent and complicated scripting for the controller and data pipeline itself is located on a campus computer and cannot be accessed currently.
